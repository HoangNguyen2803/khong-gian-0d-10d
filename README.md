# KHÔNG GIAN 0D–10D

An interactive educational website for exploring geometric dimensions from 0D to 10D.

## Features

- Explore dimensions from 0D to 10D.
- Interactive rotation and perspective projection.
- Adjustable complexity and projection distance.
- Mouse and touch controls.
- Automatic rotation and random orientations.
- Responsive interface for desktop and mobile.
- Built with HTML, CSS, and vanilla JavaScript.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. No installation, build process, or external library is required.

## Technology

- HTML5
- CSS3
- JavaScript
- Canvas 2D API

## Notes

Dimensions above 3D are represented through mathematical projections
onto the 2D screen. They are visualizations, not direct displays of
higher-dimensional space.
